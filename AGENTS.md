# AGENTS.md

Operating notes for AI coding agents working on this LibreChat fork. This
complements `README.md` (product/feature docs) with environment- and
workflow-specific guidance. Prefer the canonical npm scripts in `package.json`
over ad-hoc commands.

## Cloud Agent development environment

The Cloud Agent environment is repository-managed via `.cursor/environment.json`
and the scripts in `.cursor/setup/`:

- `install` → `.cursor/setup/install.sh`: installs MongoDB, generates local
  config, runs `npm ci`, then builds packages + client via `npm run frontend`.
- `start` → `.cursor/setup/start.sh`: starts and health-checks MongoDB.
- `terminals`: runs `npm run backend:dev`, which serves the built client at
  `http://localhost:3080`.

This is a multi-repo workspace: the repositories are checked out under
`/agent/repos/` and the working directory for environment commands is the
workspace root, not the repo. Always `cd /agent/repos/LibreChat` before running
the setup scripts or npm scripts (the committed environment commands already do
this).

## Datastore

- MongoDB is pinned to the 8.0 series and must be running for the backend.
  It is installed only when missing and started (dbpath `/data/db`, port
  `27017`, `--noauth`-style local dev) by `.cursor/setup/start.sh`. Re-run that
  script any time to (idempotently) ensure Mongo is up.
- Meilisearch and the RAG API are not part of this environment; message search
  is disabled (`SEARCH=false` in the generated `.env`). File/RAG features that
  require the RAG API are not available here.

## Configuration & secrets

- `.env` is generated from `.env.example` by the install script (host bound to
  `0.0.0.0`). It is gitignored — do not commit it.
- `librechat.yaml` is generated by the install script and enables the **Mistral**
  custom endpoint. It references API keys as `${VAR}` only; no secrets are
  written to it. It is gitignored.
- AI provider keys are read from environment secrets at runtime. Known state in
  this environment:
  - `MISTRAL_API_KEY` — valid; **use Mistral (`mistral-small-latest`) as the
    default demo/test endpoint.**
  - `ANTHROPIC_API_KEY` — valid.
  - `OPENAI_API_KEY` — currently invalid (returns 401). If a broken default
    `openAI` endpoint gets in the way during local testing, start the backend
    with `OPENAI_API_KEY` unset.

## Common commands

- Full build (packages + client): `npm run frontend`
- Run backend (dev, nodemon): `npm run backend:dev` (serves on `:3080`)
- Lint: `npm run lint` (fix: `npm run lint:fix`)
- API unit tests: `npm run test:api`
- Client unit tests: `npm run test:client`
- Create a local user (no UI needed):
  `npm run create-user -- <email> "<name>" <username> "<password>" --email-verified=true`

## Testing preferences

- Use MongoDB 8.x for local/dev testing (matches the pinned install).
- Use the Mistral endpoint for end-to-end chat verification.
